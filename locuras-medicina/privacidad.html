Política de privacidad

Última actualización: 4 de noviembre de 2026.

Esta política explica qué datos usa el Publicador de Locuras de la Medicina (la «aplicación»), la herramienta interna con la que el canal Locuras de la Medicina sube sus propios vídeos a YouTube.

Quién usa la aplicación

La aplicación la usa únicamente el propietario del canal Locuras de la Medicina, con su propia cuenta de Google. No está abierta al público y no la usan otras personas.

Qué datos de Google usa y para qué

  • Permiso para subir vídeos (youtube.upload): para subir a nuestro canal los vídeos aprobados por el autor, con su título, descripción y hora de publicación.
  • Permiso de solo lectura de YouTube (youtube.readonly): solo para leer el nombre del canal y comprobar que la conexión es la correcta.

La aplicación no lee, guarda ni analiza vídeos, comentarios, suscriptores, mensajes ni ningún otro dato de la cuenta, y no accede a datos de otros usuarios.

Cómo se guardan

El permiso de acceso (token) se guarda cifrado como secreto en GitHub Actions, donde se ejecuta la aplicación, y solo lo usa la propia aplicación para subir los vídeos. La aplicación guarda únicamente el identificador y el enlace de los vídeos que ha subido, para no subir dos veces el mismo.

Con quién se comparten

Con nadie. Los datos no se venden, no se ceden a terceros y no se usan para publicidad. El uso de la información recibida de las API de Google cumple la Política de datos de usuario de los servicios de API de Google, incluidos los requisitos de uso limitado.

Servicios de YouTube y Google

La aplicación usa los servicios de la API de YouTube (YouTube API Services). Al usarla, también se aplican las Condiciones del servicio de YouTube y la Política de privacidad de Google.

Cómo retirar el acceso

El acceso se puede retirar en cualquier momento desde la página de permisos de tu cuenta de Google. Al retirarlo, la aplicación deja de poder subir vídeos y no conserva ningún otro dato.

Contacto

Para cualquier pregunta sobre esta política, escribe al canal Locuras de la Medicina a través de YouTube.
